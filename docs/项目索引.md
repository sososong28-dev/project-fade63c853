## 运维铁律

1. **定时自愈必须先 login 再巡检/重连。** 后台 JWT 过期会 401，巡检误报账号为空、卡券未绑定，且无法 enable/connect。
2. WebSocket 掉线后账号常变成 `disabled`，顺序：login → enable → connect。
3. Cookie 本身失效时 connect 救不回来，必须闲鱼 App 扫码，禁止伪造 Cookie。
4. 不重复实现发货引擎，一律走已部署后台。
